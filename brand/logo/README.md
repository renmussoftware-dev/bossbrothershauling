# Logo master

`boss-brothers-shield.png` — 3000 x 4118, transparent background, supplied by
the owners. This is the source of truth for every mark on the site.

Generated from it (do not edit these by hand — regenerate):

| File | What it is |
|---|---|
| `public/logo-mark.png` | 320px-tall site mark, used in the nav, footer and on the hero truck door |
| `public/icon-32.png`, `public/icon-512.png` | Browser favicons |
| `public/apple-icon-180.png` | iOS home-screen icon (black ground — iOS composites on white) |
| `public/og.png` | 1200x630 social share card |
| `brand/qr/*-shield.svg`, `*-truck-panel.svg` | QR codes with the shield in the middle |

The web copies are quantized with `pngquant` to keep the page light; the master
here is untouched.
